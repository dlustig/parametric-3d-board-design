# Cutting Board Pattern Designer

A React + TypeScript + Vite single-page app for designing cutting board patterns. Install dependencies with `pnpm install`, then run `pnpm dev` for a local dev server, `pnpm test` to run the Vitest unit suite, and `pnpm build` to produce a production build (`pnpm typecheck` runs the standalone type check). See the spec at `docs/superpowers/specs/2026-09-24-cutting-board-pattern-designer-design.md` and the implementation plan at `docs/superpowers/plans/2026-09-24-cutting-board-v1.md` for the full design.
